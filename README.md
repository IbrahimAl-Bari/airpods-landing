AirPods Pro 3 A visually rich product landing page built with Next.js, recreating Apple's AirPods Pro 3 marketing site with interactive animations and scroll-driven storytelling.

Preview airpods-landing-eight.vercel.app

Overview This project showcases a modern, animation-heavy product page focused on smooth transitions, clean visuals, and an immersive scrolling experience similar to Apple's own product pages.

Features

Full navigation (Store, Mac, iPhone, Watch, Vision, AirPods)
Hero section with pricing and CTA
Feature highlights (ANC, battery life, heart rate sensing, water resistance, etc.)
Expandable "Take a Closer Look" detail sections
Embedded product video
Scroll-based storytelling for chip and noise-cancellation stats

Roadmap Remaining nav pages (Mac, iPhone, Watch, Vision) Mobile responsiveness pass Accessibility audit Dark/light mode toggle

Tech Stack

Next.js
React
Tailwind CSS
GSAP

Installation Clone the repository:

git clone https://github.com/IbrahimAl-Bari/airpods-landing.git
cd airpods-landing
npm install
npm run dev
